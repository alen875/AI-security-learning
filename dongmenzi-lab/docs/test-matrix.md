# B01 靶场测试矩阵

本表承接课程计划书中的 46 个检查点，并加入 T3 的 5 个检查点、注册功能的 2 个检查点、门户功能入口的 2 个检查点，共 55 项。`tests/test_lab.py` 使用本地临时数据库验证核心逻辑；需要实际 Windows/Kali 虚拟机、浏览器或教师许可的项目标为**现场待验**。下列预期不能当作测试结果。

| 范围 | 检查点 | 方式与通过条件 |
|---|---|---|
| 环境 E01–E02 | Windows 离线安装、私网与公网边界 | 现场待验：在批准虚拟机离线安装；Kali 私网可访问，未授权网段不可达 |
| 环境 E03–E04 | 安全默认、互斥模式 | 自动：无效或组合模式拒绝；现场核对启动横幅和状态接口 |
| 环境 E05–E06 | 建表种子、缺库拒绝 | 自动：结构、行数、外键及缺库失败 |
| 环境 E07–E08 | 凭据隔离、断网运行 | 静态检查 `.gitignore`；现场待验：断网功能正常且运行目录无外部依赖 |
| 业务 A01–A03 | 登录、失败、注销、未登录访问 | 自动：有效账号登录、失败限速、令牌注销、未登录拒绝 |
| 业务 A04–A07 | 设备归属、本人记录、审计与重置角色 | 自动：双身份与三模式权限检查 |
| 业务 A08–A09 | 非法输入、重复点击 | 自动覆盖部分非法输入；浏览器重复点击现场待验 |
| 业务 A10–A11 | 普通账号注册与角色边界 | 自动验证固定维护员角色、同名和非法输入被拒；浏览器操作现场待验 |
| T1-01–T1-04 | 本人/他人/换身份/换对象 | 自动：同一只读请求比较四种模式；第二身份；无数据写入 |
| T1-05–T1-08 | 其他路径、未登录、同条件复测、审计 | 自动：设备和列表保持授权；会话要求、审计及摘要 |
| T2-01–T2-03 | 正常查询、教学输入、修复前后 | 自动：普通编号结果一致，预审布尔条件只在 `sqli` 扩大虚构索引结果 |
| T2-04–T2-09 | 边界输入、其他路径、数据隔离、完整性、限额与错误 | 自动覆盖空值、长度、普通特殊字符、主库摘要和错误隐藏；实际超时/负载现场待验 |
| T3-01–T3-05 | 普通预览、BP 参数变化、修复复测、真实复核员、数据完整性 | 自动验证四种模式中的状态差异、令牌要求、正常角色和业务摘要；Burp 界面操作现场待验 |
| 前端 U01–U06 | 异步交互、加载/空/错误、窄屏与模式标识；门户占位入口 | 六个后端占位接口和未知入口已自动检查；本机 Edge 已检查主要按钮、弹窗与 390 像素宽度；完整键盘和现场双机流程待验 |
| 审计 L01–L02 | 登录、拒绝、T1/T2、重置留痕与权限 | 自动覆盖主要事件和审计访问；现场核对日志最小化 |
| 重置 R01–R04 | 基线、拒绝、历史保留、失败回滚 | 自动：设备内容变更后恢复，缺令牌拒绝，故障注入回滚 |
| 回归 G01–G02 | 分时训练和全流程 | 自动覆盖主要 API；两人连续课堂操作与重置现场待验 |

**现场记录格式：**编号、日期、执行者角色、批准环境、构建号、模式、种子版本、步骤、预期、实际、证据路径、限制、结果（通过/失败/未执行）。失败时保留原始记录并说明修订动作。不要把“自动化部分通过”写成全部 55 项完成。
